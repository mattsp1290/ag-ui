# Rust SDK

The Rust SDK consists of two crates:

- ag-ui-core: shared types and events
- ag-ui-client: client utilities and concrete agents like HttpAgent

## Getting started

Version 0.2.0 is currently available from this repository checkout. Use path dependencies on `sdks/community/rust/crates/ag-ui-core` and `sdks/community/rust/crates/ag-ui-client` until publication. See the [client overview](/sdk/rust/client/overview) for an example.
